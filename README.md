# AI 队友（AiTeammate）

在《杀戮尖塔 2》中加入一个由大语言模型操控的 AI：多人模式下作为队友与真人协作；单人模式下可以**独自爬塔**，你随时能打断它并和它说话。

## 语言 / Language

- 中文（简体）与 English 随游戏语言自动切换：设置页、聊天面板、选人界面、提示消息、内置人格均已本地化。
- The mod follows the game language (Simplified Chinese / English). Other game languages fall back to English.
- AI 的聊天、建议理由与思考摘要也会跟随游戏语言输出。

## 支持版本

| 游戏版本 | 支持情况 |
|---|---|
| 0.107.1（正式版） | ✅ 实机验证 |
| 0.111.0（beta） | ✅ 编译/打包验证（需对应版本游戏） |

本 Mod 以 **多版本 bundle** 形式发布：`AiTeammate.dll` 是加载器，实际逻辑在 `lib/<游戏版本>/AiTeammate.Content.dll`，加载器会自动选择匹配当前游戏的版本。

## 前置依赖

### RitsuLib（必需）

本 Mod 硬依赖 **STS2-RitsuLib**。请安装与游戏版本匹配的 RitsuLib 运行时：

- 安装为一个完整的 `mods/STS2-RitsuLib/` 文件夹（含 `compat/`、`shared/`、`assets.zip`、`mod_manifest.json` 等），不要只复制单个 DLL。
- 同时兼容正式版与 beta 时，请使用 RitsuLib 提供的 variant-pack（包含多个 `compat/<版本>/`）。

## 安装

1. 安装匹配当前游戏版本的 RitsuLib。
2. 将 `AiTeammate/` 整个文件夹放入游戏的 `mods/` 目录。
3. 启动游戏。加载器会在日志中打印选择的内容变体。

## 配置

所有设置都在 **游戏内 → 设置 → 模组设置 → AI 队友** 中完成（由 RitsuLib 提供设置页），不需要再手动编辑 JSON：

- **AI 引擎**：DeepSeek / OpenAI / Ollama，各自的 API Key、模型、Base URL；可选模型思考模式；「连接测试」。
- **决策**：战斗决策超时、聊天超时、非战斗重试次数；是否向 AI 展示抽牌堆/弃牌堆/消耗堆内容；战斗内/战斗外是否允许 AI 主动调用只读工具（牌堆、遗物、药水、队友状态、地图路线等；多人模式下可读队友牌堆）。
- **人格**：选择/新建/删除人格，编辑背景故事、战斗哲学、交流风格、决策原则；长期记忆与人格成长开关。
- **聊天与建议**：AI 聊天、聊天气泡、自动发言冷却、提示词聊天历史；卡牌建议开关、回合开始自动建议、建议数量上限。
- **维护**：内容缓存自动刷新/手动重建、决策日志与请求日志开关、日志保留数量、打开日志目录、重置全部设置。

推荐 **deepseek-v4-flash**（便宜且够用）。

## 多人模式

- AI 队友会**独立投票选路**：根据整幕地图、血量、金币和构筑自己决定走向，不再单纯复制人类投的节点；人类投票只在它决策失败/超时时作为兜底，保证不卡住地图。
- 它会按需查看自己的牌堆、遗物、药水，也可以主动查看**队友**的手牌、牌堆、金币、遗物与药水（只读，不会改变任何状态）。抽牌堆顺序不会透露。
- 想减少开销可以在设置里关闭「战斗决策可调用工具」或「战斗外决策可调用工具」。

## AI 独自爬塔（单人模式）

设置页新增了「单人爬塔」分区：

1. **开始方式**
   - 打开「AI 独自爬塔（单人模式）」开关后，**正常开一局单人模式**，AI 会立刻接管本地玩家；
   - 或直接点「开始 AI 独自爬塔」，从主菜单立刻开一局（角色由「AI 角色」选择，默认随机）。
2. **它会做什么**：选路、战斗出牌/用药水、拿奖励与选牌、商店购物、篝火、事件、宝箱、进入下一幕，全部由 LLM 决策自动完成。
3. **随时打断**
   - 在聊天框发消息 = 打断 AI，它会先停下（保留当前回合/当前界面），回复你之后约 3 秒自动继续；
   - 聊天面板标题栏的 **⏸ / ▶** 按钮可以立即暂停或继续（设置页「暂停 / 继续 AI」同效）；
   - 连续发消息会持续延长暂停；暂停期间游戏不会卡死，AI 会等你。
4. **指挥它**：聊天里的指令（如「先打左边」「给我留个药水」）会被解析成战术指令，在接下来的战斗里生效。
5. **兜底**：遇到 Mod 事件特有的小游戏界面时，AI 会等几秒后交给内置的自动处理；实在处理不了会**自动暂停并提示你手动处理**，处理完点 ▶ 继续。

> 单人模式下你仍然是本地玩家：可以随时手动点牌/结束回合（AI 会按自己的节奏继续）。想自己操作时，先点 ⏸ 暂停 AI。

## 日志

- 决策日志：`user://ai_teammate/logs/session.log`（默认开启，可在设置中关闭）
- 请求/响应日志：`user://ai_teammate/logs/ai_traffic.log`（默认关闭）
- 设置页「打开日志目录」可直接定位。

Windows 上 `user://` 通常位于 `%AppData%\SlayTheSpire2\`。

## 特殊兼容

- **海克斯符文（HextechRunes）**：可选软兼容。检测到该 Mod 时，AI 会参与符文选择/重投；未安装时自动跳过。
