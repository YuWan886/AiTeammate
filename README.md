## 使用方法

1. 先安装mod进入游戏
2. `win + r` 输入 `%AppData%\SlayTheSpire2\ai_teammate`
3. 打开 `config.json`
   
``` json
  "backends": {
    "DeepSeek": {
      "apiKey": "填入你的key",
      "model": "deepseek-v4-flash",
      "baseUrl": "https://api.deepseek.com/v1"
    }
  }
```
4. 推荐用 **deepseek-v4-flash** ，因为真的很便宜。
